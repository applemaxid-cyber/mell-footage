# Футажи Меллстрой

Статический сайт-каталог футажей из TikTok-аккаунта [@footage_me1](https://www.tiktok.com/@footage_me1).

- Поиск по описанию, хештегам и своим тегам (регистр и «ё» не важны, слова ищутся в любом порядке, найденное подсвечивается).
- Фильтр по тегам, сортировка (новые / старые / просмотры / лайки).
- Видео воспроизводятся через официальный плеер TikTok (embed), сами файлы не копируются.

## Запуск
```bash
python3 -m http.server 8000   # открыть http://localhost:8000
```
Сайт статический — можно выложить на GitHub Pages / Vercel / Netlify как есть.

## Как наполнить каталог (без ручного ввода ссылок)
TikTok блокирует получение списка видео с серверов, поэтому список собирается в вашем браузере:
1. Откройте https://www.tiktok.com/@footage_me1, нажмите F12 → Console.
2. Вставьте содержимое `tools/collect.js` и нажмите Enter — страница сама прокрутится до конца, и скачается `tiktok_export.json`.
3. Положите файл в `projects/mellstroy-footage/` и выполните `python3 scripts/sync.py` — он создаст `data/videos.json` и скачает превью.

Запасные варианты: список ссылок/ID в `links.txt` или `pip install yt-dlp` (с домашнего IP может взять профиль целиком).
В `data/videos.json` в поле `"tags"` можно вручную добавлять слова для поиска; повторная синхронизация их не затирает.
